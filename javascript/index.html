GraalJS

High-performance embeddable JavaScript runtime for Java
Quick Start Documentation

Benefits

JavaScript for Java

Use JavaScript modules and scripts directly in Java

ECMAScript Compliant

Fully implements the ECMAScript 2026 Language Specification

Fastest JavaScript on the JVM

Graal JIT compiles JavaScript for native code speed

Modern JavaScript for the JVM

An upgrade path for Nashorn and Rhino applications to ECMAScript 2025

Script Java with JavaScript

Extend applications with JavaScript that interacts with Java classes and frameworks

WebAssembly Integration

Use WebAssembly modules through the JavaScript WebAssembly API

How to Get Started

1. Add GraalJS as a dependency from Maven Central


  <dependency>
    <groupId>org.graalvm.polyglot</groupId>
    <artifactId>polyglot</artifactId>
    <version>25.0.4.1</version>
  </dependency>
  <dependency>
    <groupId>org.graalvm.polyglot</groupId>
    <artifactId>js</artifactId>
    <version>25.0.4.1</version>
    <type>pom</type>
  </dependency>

or 


  implementation("org.graalvm.polyglot:polyglot:25.0.4.1")
  implementation("org.graalvm.polyglot:js:25.0.4.1")

2. Embed JavaScript code in Java


  import org.graalvm.polyglot.Context;

  try (Context context = Context.create()) {
      context.eval("js", "console.log('Hello from GraalJS!')");
  }
